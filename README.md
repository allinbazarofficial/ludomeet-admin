# LudoMeet admin

Static files for the LudoMeet admin panel (admin.playludomeet.com) and website (playludomeet.com).
No secrets here: access is enforced by Firebase Auth and Firestore security rules.

Install/update on the server:

    curl -fsSL https://raw.githubusercontent.com/allinbazarofficial/ludomeet-admin/main/install.sh | bash
